Printing guide

Use the Mac app, or send a PDF from Terminal.

Before you start

You need an active mySoC account with Unix access enabled and available print quota. Use your SoC username and password.

On SoC Wi-Fi, try a direct connection. Elsewhere, you may need NUS VPN and the SoC jump host. Jump-host access requires manual SSH-key registration. Follow the SoC network access guide for current network requirements.

Using SimplyPrint @ SoC

  1. Open the downloaded DMG and drag SimplyPrint @ SoC into your Applications folder in Finder. Open it from Applications.
  2. In Account, enter your SoC username and password, then Save. For jump-host access, choose your registered private key and enter its key passphrase.
  3. Choose Connect. On first connection, verify the server fingerprint with SoC before trusting it.
  4. Open a PDF with ⌘ O. Select a printer and review the preview, pages, copies, layout, sides, and banner.
  5. Choose Print and confirm the document, location, and queue. Check Jobs and Queues, then collect your pages.

PDFs must be readable, unlocked, and no larger than 1 GB. “Submitted” means the server accepted the job; it does not confirm paper has printed. If the outcome is unknown, check the queue before sending again.

Printing from Terminal

Replace YOUR_SOC_USERNAME with your SoC username. These examples use psc008 (A4, black and white, double-sided, with a banner). Check the directory below before choosing a queue.

1. Create a private upload folder

On your Mac, run:

ssh YOUR_SOC_USERNAME@stu.comp.nus.edu.sg 'umask 077; mktemp -d /tmp/print-soc.XXXXXXXX'

Save the folder path it returns. In the examples below, replace /tmp/print-soc.ABCDEFGH with that exact path.

2. Upload your PDF

Replace ./document.pdf with the path to your PDF. Keep paths containing spaces in quotes.

scp "./document.pdf" YOUR_SOC_USERNAME@stu.comp.nus.edu.sg:/tmp/print-soc.ABCDEFGH/document.pdf

If direct access is unavailable, register your key first, then use these equivalents for the connection and upload:

ssh -J YOUR_SOC_USERNAME@sjump.comp.nus.edu.sg YOUR_SOC_USERNAME@stu.comp.nus.edu.sg
scp -J YOUR_SOC_USERNAME@sjump.comp.nus.edu.sg "./document.pdf" YOUR_SOC_USERNAME@stu.comp.nus.edu.sg:/tmp/print-soc.ABCDEFGH/document.pdf

Set IdentityFile ~/.ssh/print_soc_ed25519 for sjump.comp.nus.edu.sg in ~/.ssh/config as described in the SSH-key guide. When using the jump host to create the upload folder, run the first command interactively, then umask 077; mktemp -d /tmp/print-soc.XXXXXXXX on the server.

3. Submit and inspect the queue

Connect to the Unix server. Run these commands on the server:

lpr -P psc008 /tmp/print-soc.ABCDEFGH/document.pdf
lpq -P psc008

For two copies, use lpr -P psc008 -# 2 /tmp/print-soc.ABCDEFGH/document.pdf. Select and arrange pages in your PDF before uploading; these commands print the supplied document.

4. Cancel or remove the upload

To cancel your own job, copy its exact job ID from lpq. Replace YOUR_JOB_ID below. Do not use a command that cancels everyone’s jobs.

lprm -P psc008 YOUR_JOB_ID

After confirmed submission or cancellation, remove only your uploaded file and its empty folder:

rm -- /tmp/print-soc.ABCDEFGH/document.pdf
rmdir -- /tmp/print-soc.ABCDEFGH
exit

If something goes wrong

macOS will not open the app
Download the current release and copy the app to Applications. If macOS says the developer cannot be verified, try opening the app once, then go to System Settings → Privacy & Security → Open Anyway. Check that the app name is SimplyPrint @ SoC, then choose Open. This release is not Apple-notarized. See Apple’s opening guide. If macOS reports malware or damage, stop rather than overriding that alert.
Cannot connect
Check your network, VPN, Unix access, and SoC credentials. For jump-host access, complete manual key registration.
Key cannot be unlocked
The key passphrase is the one chosen when creating the key. It can differ from your SoC password.
Server identity changed
Stop and confirm the new fingerprint with SoC IT. Do not delete your trusted host entry merely to bypass the warning.
Unknown print outcome
Check lpq or the app’s Queues page before resubmitting to avoid duplicate printing.
